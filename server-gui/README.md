# ClassView — серверный GUI

Просмотр камеры и микрофона интерактивных панелей по запросу и запись в файл.

## Установка (ROSA / MOS)
    tar xzf classview-server-gui.tar.gz && cd server-gui && sudo ./install.sh

Запуск: меню → ClassView или `classview`.

## Первый запуск
1. **Настройки** → пароль потоков (тот же, что будет в конфиге панелей), папка записей,
   срок хранения. Если используете справочник filedrop — его адрес и токен:
   тогда IP панелей подтягиваются автоматически при смене по DHCP.
2. **Импорт CSV** — тот же файл `hostname,ip`, что для раскатки filedrop.
   Берутся только панели (`p1747-…`), корпус и кабинет разбираются из имени.
3. Двойной клик по панели (или Enter) → окно просмотра.

## Окно просмотра
- «● Запись» (клавиша R) — запись в `Папка записей/<корпус>-<кабинет>/<хост>_<дата>.mp4`.
  Формат fragmented MP4: файл читается, даже если запись оборвалась.
- F или двойной клик — полный экран, Esc — выход.
- Несколько кабинетов можно открыть одновременно.
- Точка статуса в списке: зелёная — панель в сети, серая — недоступна, синяя — открыт просмотр.

## Протокол с панелью (для панельной части)
| Действие сервера | Путь на панели | Точка в трее панели |
|---|---|---|
| Просмотр | `rtsp://<login>:<pass>@<ip>:8554/cam` | зелёная |
| Запись (дополнительно к просмотру) | `rtsp://…/rec` | красная |
| Окно закрыто | — | нет |

Требования к конфигу MediaMTX на панели (проверено тестом):
- `protocols: [tcp]` — иначе UDP-сессии «висят» после закрытия окна и точка не гаснет;
- путь `rec`: `source: rtsp://127.0.0.1:8554/cam`, `sourceOnDemand: yes`,
  `sourceOnDemandCloseAfter: 1s`.

## Данные
- Настройки: `~/.config/classview/config.json` (права 600)
- База (панели, архив, журнал): `~/.local/share/classview/classview.db`

## Диагностика
- «Панель не отвечает» — нет MediaMTX на панели, неверный пароль или порт 8554 закрыт.
- Серая точка при живой панели — проверьте IP в списке или доступность справочника.
- Запись сразу обрывается — нет ffmpeg: `sudo dnf install ffmpeg`.
- Окно не запускается с ошибкой xcb — не хватает пакета xcb-util-cursor.

## Важно после обновления
- Если запись даёт «Cannot assign requested address»: в Настройках «Путь записи» должен быть `cam` (не `rec`). Старый конфиг из ~/.config/classview может хранить прежнее значение.
- Живой звук в просмотре обеспечивается выводом mpv `ao=pulse` (задано в player.py). Если звука нет — проверьте, что ffmpeg/mpv на сервере видят PulseAudio.
