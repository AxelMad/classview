# ClassView

Просмотр и запись видео и звука с камер интерактивных панелей в классах — по запросу,
из единого приложения на сервере. Панель ничего не транслирует, пока к ней не подключились;
на экране панели горит индикатор (зелёная точка — идёт просмотр, красная — запись).

Разработано для школ с интерактивными панелями на Linux (ROSA / МОС), но подходит для
любой сети с похожими панелями — номер школы, подсети, справочник имён настраиваются.

## Как это устроено

```
┌─────────────────┐        RTSP/TCP (по запросу)        ┌──────────────────┐
│  Сервер (GUI)   │ ─────────────────────────────────► │   Панель         │
│  ClassView      │                                     │   MediaMTX       │
│  + libmpv       │ ◄───────── видео H.264 + звук ───── │   + ffmpeg       │
│  + ffmpeg (rec) │                                     │   + индикатор    │
└────────┬────────┘                                     └──────────────────┘
         │ hostname → IP
         ▼
   Справочник имён (filedrop directory) или статический CSV
```

- **Сервер** (`server-gui/`) — GUI на PySide6: список панелей, просмотр (libmpv, низкая
  задержка), запись (ffmpeg, без перекодирования), архив, журнал подключений. IP панелей
  берутся из справочника или из импортированного CSV.
- **Панель** (`panel/`) — MediaMTX с захватом по требованию (`runOnDemand`): камера отдаёт
  H.264 сама, микрофон кодируется в Opus. Захват запускается от пользователя графической
  сессии, индикатор в трее показывает состояние.
- Один сервер обслуживает одну L2/L3-зону. Для изолированных подсетей (разные корпуса)
  поднимается отдельный экземпляр сервера — приложение и пакеты те же, отличаются настройки.

## Требования

- Панели и сервер: Linux (проверено на ROSA / МОС 12, ядро 5.4+), `ffmpeg`, `v4l2-utils`.
- Сервер дополнительно: Python 3.8+, PySide6, `libmpv` (иначе запасной плеер Qt), `mpv`.
- Панели: USB-камера с аппаратным H.264 (`v4l2 -input_format h264`), PulseAudio.
- Одинаковая схема имён хостов: `<тип><школа>-<корпус>-<кабинет>-<номер>`
  (`p` — панель, `n` — ноутбук, `m` — моноблок), напр. `p1747-0-305-0`.

## Установка сервера

```bash
cd server-gui
sudo ./install.sh
classview        # запуск от обычного пользователя
```

В «Настройки» укажите: номер школы, пароль потоков (общий с панелями), путь просмотра/записи
(`cam`), адрес и токен справочника (если используется), папку записей. Импортируйте список
панелей кнопкой «Импорт CSV» (формат `hostname,ip`, см. `panels.example.csv`).

## Раскатка панелей

```bash
cd panel
# SCHOOL ограничивает раскатку одной школой; DIR_TOKEN/DIR_URL — свежие IP из справочника
SCHOOL=1747 DIR_URL=http://127.0.0.1:8781 DIR_TOKEN=<токен> \
  ./deploy/rollout-panels.sh panels.csv <пароль_потоков>
```

Скрипт спросит единый пароль sudo панелей, поставит пакет на каждую и выведет сводку
(служба + определившийся микрофон). Для одиночной панели: `sudo ./install.sh <пароль_потоков>`.

## Настройка под свою школу

- **Номер школы** — поле «Номер школы» в настройках сервера и переменная `SCHOOL=` при раскатке.
  Пусто — принимаются панели любой школы (`p<цифры>-…`).
- **Подсети** — приложение не привязано к адресам; IP берутся из справочника или CSV.
- **Справочник имён** — HTTP filedrop directory (`GET /resolve?name=<host>`, заголовок
  `X-Filedrop-Token`). Не обязателен: без него IP берутся из CSV. Свой резолвер можно
  подставить в `server-gui/classview/resolver.py`.
- **Микрофон** — захват выбирает источник PulseAudio по подстроке `TOUCHDEVICE` (микрофон
  тачскрина), затем любой USB-вход, кроме мёртвого. Логика в `panel/bin/classview-capture.sh`,
  функция `find_mic_source` — при другом железе поправьте подстроку.

## Юридическое

Запись видео и звука в классе — обработка персональных данных. До использования
оформите основания по местному законодательству (в РФ — приказ, согласия законных
представителей, уведомление сотрудников, таблички о видеонаблюдении). Видимый индикатор
и журнал подключений сделаны в помощь такому согласованию, но не заменяют его.

## Безопасность

- Пароль потоков и токен справочника **не хранятся в репозитории** — задаются в настройках
  на месте. Не коммитьте реальные `config.local.json`, токены и CSV с адресами (см. `.gitignore`).
- MediaMTX на панели слушает только TCP и отдаёт поток по паролю; публикация и API — только
  с самой панели (`127.0.0.1`).
