# ClassView — панельная часть

Ставится на каждую интерактивную панель. Камера и микрофон включаются только когда
сервер открывает поток, и гаснут после закрытия. Индикатор в трее: зелёная точка —
идёт просмотр, красная — идёт запись, ничего — никто не подключён.

## Установка на одну панель
    sudo ./install.sh <пароль_потоков>

`<пароль_потоков>` — тот же, что задан в GUI сервера (Настройки → Пароль потоков).

## Как работает
- MediaMTX (служба `classview-panel`) слушает TCP :8554, только чтение по паролю.
- Путь `cam` — просмотр, `rec` — запись. Захват (`classview-capture.sh`) стартует по
  требованию: камера отдаёт H.264 сама, микрофон кодируется в Opus через ffmpeg.
- Индикатор опрашивает локальный API MediaMTX и рисует точку в трее.

## Массовая раскатка
С сервера, по тому же CSV, что для filedrop:
    ./deploy/rollout-panels.sh panels.csv <пароль_потоков>

## Проверка
    systemctl status classview-panel
    journalctl -u classview-panel -f     # смотреть при подключении с сервера

## Если камера занята
Если учитель ведёт видеосвязь (камера уже открыта другим приложением), ffmpeg не сможет
её захватить, поток не поднимется, и на сервере будет «Панель не отвечает». Это ожидаемо:
одновременный захват V4L2 невозможен.

## Данные
- Конфиг: `/opt/classview/config/mediamtx.yml` (пароль внутри, права 640)
- Логи: `journalctl -u classview-panel`
